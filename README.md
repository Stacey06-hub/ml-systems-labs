# ML Systems Lab 1

## Overview
This lab compares the baseline performance of two machine learning models.

## Dataset
Breast Cancer Wisconsin Diagnostic dataset provided by scikit-learn.

## Models
- Logistic Regression
- Random Forest Classifier

## Measurements
- Test accuracy
- Median training time
- Median single-sample inference latency
- Model file size
- Peak process memory

## Project Structure
- `lab01/src/` — source code
- `lab01/results/` — CSV measurements and saved models
- `lab01/report.md` — lab report
- `requirements.txt` — Python dependencies
- `.gitignore` — files excluded from Git

## How to Run
Activate the virtual environment and run this command from the project root:

```cmd
python lab01\src\baseline.py
